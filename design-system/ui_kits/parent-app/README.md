# 학부모·학생 앱 UI 킷

기능정의서(`학원 통학버스 통합관리 시스템.pdf`)의 학부모·학생 MVP Scope와
`학부모 유저플로우.png`, `학생 유저플로우2.png`를 그대로 옮긴 클릭 스루입니다.

## 화면
| 화면 | 유저플로우 대응 | 파일 |
| --- | --- | --- |
| 로그인 | 로그인 → 학부모/학생 코드 입력 | `ParentScreens.jsx` LoginScreen |
| 홈 | 홈 (오늘 운행, 알림, 등원 상태 드롭다운) | HomeScreen |
| 실시간 운행 정보 → 지도 | 실시간 운행 정보 → 지도 페이지 | LiveMapScreen |
| 상세 노선 | 노선 자세히 보기 → 상세 노선 페이지 | RouteDetailScreen |
| 탑승 위치 변경 | 탑승일정/위치 변경 → 스케줄 변경 페이지 | ScheduleScreen |
| 알림 설정 | 설정 아이콘 → 설정 페이지 → 알림 설정 | SettingsScreen |

## 플로우에서 그대로 지킨 규칙
- 아이디/비밀번호 없이 **부여된 코드 6자리**로만 로그인합니다.
- **도착 지연 알림은 on/off 불가** — Switch를 disabled로 두고 이유를 sublabel에 적습니다.
- 학생 계정에는 등원 여부 변경과 탑승 위치 변경이 없습니다(학부모 전용).
- 탑승 위치 변경은 즉시 반영이 아니라 **변경 신청** → 학원 확인입니다.

## 대체한 것
- 지도는 `ui_kits/MapSurface.jsx` 플레이스홀더입니다. 실제 타일·SDK는 연동 시 교체하세요.
