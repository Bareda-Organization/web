# 매니저 앱 UI 킷 (버스기사 + 동승자)

`버스기사 유저플로우.png`, `버스기사 유저플로우2.png`, `동승자 유저플로우.png`와
기능정의서의 버스기사·버스 동승자 Scope를 옮긴 클릭 스루입니다. 기본 테마는 **다크**입니다.

## 화면
| 화면 | 유저플로우 대응 | 파일 |
| --- | --- | --- |
| 로그인 | 버스기사/동승자 코드 입력 (실패 시 재입력) | `ManagerScreens.jsx` ManagerLogin |
| 담당 운행 노선 | 담당 운행 노선 → 정류장 리스트 | ManagerHome |
| 운행모드 | 운행모드 버튼 → 현재/다음 정류장, 도착 알림 전송 | DriveMode |
| 정류장 탑승자 | 정류장별 탑승자 명단 → 탑승/미등원/하차, 일괄 처리 | StopRoster |
| 지연 알림 | 도착 지연 알림 전송 → 사유 + 5분 단위 시간 → 전송 | DelayScreen |
| 금일 노선 지도 | 실시간 버스 위치 지도, 신규 추가/삭제 노선 | RouteMapScreen |
| 운행 종료 리포트 | 운행 종료 | RunEndScreen |

## 플로우에서 그대로 지킨 규칙
- 지연 시간은 자유 입력이 아니라 **5분 단위 선택**입니다.
- 노선의 **신규 추가는 초록, 삭제는 빨강** — Badge `added` / `removed`.
- 버스 코드로 분류되므로 앱에서 호차를 따로 선택하지 않습니다.
- 동승자는 개인별 상태(탑승·미등원·하차)를 결정하고, 일괄 탑승/일괄 하차도 가능합니다.
- 기사는 도착 알림·지연 알림 전송이 중심이고 개인 상태는 바꾸지 않습니다.
