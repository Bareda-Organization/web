`학원관계자 유저플로우.png`, `학원관계자 유저플로우2.png`, `학원 관계자 유저플로우3.png`와
기능정의서의 학원 관계자 Scope를 옮긴 클릭 스루입니다. 1440 / 1120 두 폭을 전환할 수 있습니다.

## 화면
| 화면 | 유저플로우 대응 | 파일 |
| --- | --- | --- |
| 운행 관리 | 홈 → 운행 관리 클릭 → 운행관리 페이지 | `WebScreens.jsx` Dashboard |
| 금일 운행 | 금일 운행 현황 → 금일 운행 페이지 → 호차 선택 → 명단 | TodayRun |
| 고정 노선 | 버스별 고정 노선 / 노선별 정류장 리스트 / 매니저 배치 | Routes |
| 학생 정보 관리 | 학생 관리 페이지 → 검색 → 학생 정보 페이지 → 수정·삭제 | Students |
| 학생 추가 | 추가 클릭 → 학생 추가 페이지 → 저장 → 학부모 코드 출력 | StudentAdd |
| 매니저 관리 | 매니저 관리 페이지 → 추가·수정·삭제 | Managers |
| 알림 로그 | 미탑승·등원 여부 알림 내역 | Logs |

## 플로우에서 그대로 지킨 규칙
- 금일 운행 명단에서 **추가된 탑승자는 초록, 삭제된 탑승자는 빨강**으로 표시합니다.
- 학생 저장 시 **학부모 코드와 학생 코드가 출력**됩니다 — 회원가입 코드 발급 경로입니다.
- 학생 추가 폼은 이름 / 영문 이름(선택) / 생년월일 / 보호자 전화번호 / 반 / 특이사항 / 주소 /
  요일별 하원 주소 순서로, 플로우의 입력 항목을 그대로 따릅니다.
- 매니저 항목은 이름 / 생년월일 / 전화번호 / 근무 시간이고, 저장하면 매니저 코드가 발급됩니다.
- 검색은 검색창 입력 후 검색 버튼 또는 Enter로 동작합니다.
